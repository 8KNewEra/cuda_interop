CUDA Master VideoViewer 操作マニュアル

8K / 16K の高解像度動画を、NVIDIA GPU だけで再生・確認・書き出しするためのビューアです。

はじめに

動作環境

  • Windows 10 / 11（64bit）
  • NVIDIA GPU（CUDA 対応）と最新のドライバ。NVIDIA 以外の GPU では動作しません。
  • 複数の NVIDIA GPU を搭載している場合は、書き出し（エンコード）で複数台を同時に使えます。

対応ファイル

形式MP4 / MKV / MOV / AVI
GPU でのデコード H.264（4096 × 4096 まで）、HEVC / AV1（8192 × 8192 まで）。
8K を超える映像は、複数の映像ストリームに分割した「タイル分割」の動画として扱います。
それ以外MP4 と AVI は CPU でデコードして再生できます（GPU より遅くなります）。

画面の構成

1. ヘッダー「ファイル」メニュー、表示の切り替えボタン、ファイルを保存（エンコード）ボタン。空いている部分をドラッグするとウィンドウを移動、ダブルクリックで最大化 / 元に戻します。
2. 映像ホイールで拡大縮小、ドラッグで移動、ダブルクリックで全体表示に戻ります。
3. 動画情報ファイルの基本情報、描画の速さ、GPU の使用状況を表示します。
4. ヒストグラム明るさの分布を表示します。拡大中はこの上に表示位置（ズーム）も出ます。
5. 画像処理押すと右側に画像処理パネルが開き、補正・フィルタ・確認用の表示ツールを設定できます。数字は ON にしている画像処理・表示ツールの数です。
6. 操作パネル再生・コマ送り・範囲の指定・速度・音量・画像の保存を行います。

ファイルを開く・閉じる

  • 開く：「ファイル」→「ファイルを開く…」（Ctrl+O）、または動画ファイルを映像の部分へドラッグ＆ドロップします。開くと最初から再生が始まります。
  • 閉じる：「ファイル」→「ファイルを閉じる」。
読み込みや高精度シークの間は操作が止まります 大きな動画の読み込み、正確な位置への移動、画像の保存などの間は、ほとんどのボタンが押せなくなります。 この間も「ファイルを閉じる」だけは使えます。

数値は −／＋ ボタン（押し続けると連続）、ホイール、↑↓（Shift で 10 ずつ）、直接入力で変更できます。

スライダー（再生位置と再生範囲）

  • トラックをクリック / ドラッグすると再生位置を移動します。離した位置へ正確に移動します。
  • 橙のつまみで再生範囲の開始・終了を動かします。開始のつまみは左、終了のつまみは右に張り出しているので、重なっていても掴み分けられます。
  • 再生は範囲の中で行われ、範囲を狭めると再生位置も範囲の中へ移動します。
  • 上の行に開始・終了の時刻と、再生範囲の長さ（時間とフレーム数）を表示します。

速度・音量

  • 速度：0.25x / 0.5x / 0.75x / 1x / 1.5x / 2x / 4x から選びます。
  • 音量：0〜100。

表示（ズーム・全画面）

  • 拡大縮小：映像の上でホイール。カーソルの位置を中心に拡大します。最大で 1 画素が画面上の 32 ピクセルの大きさになります。
  • 移動：左または中ボタンでドラッグ。
  • 全体表示に戻す：ダブルクリック。
  • 画素グリッド：1 画素が 12 ピクセル以上に拡大されると、画素の境目に線を表示します。
  • 全画面：F11 で映像だけを全画面表示。F11 または Esc で戻ります。
  • ヘッダーの「動画情報」「ヒストグラム」「画像処理」ボタンで、それぞれの表示 / 非表示を切り替えます。

描画フレームレート

実際に表示できたフレーム数（実測）と、目標（動画のフレームレート × 再生速度）を並べて表示し、直近 60 秒の推移をグラフにします。破線が目標です。 目標に届いていれば緑、少し足りなければ橙、大きく足りなければ赤になります。一時停止中はグラフが途切れます。

コマは落としません 処理が間に合わない場合、このアプリはフレームを飛ばさず、再生がゆっくりになります。実測が目標を下回っているときは、その分だけ再生が遅れています。

バーは「持ち時間」（1 フレームに使える時間 = 1000 ÷（動画の fps × 再生速度））に対する割合です。持ち時間に近づくと橙、超えると赤になります。フレーム間隔は再生の fps に合わせて進むため持ち時間とほぼ同じになるのが正常で、5% 以上長いときだけ色が付きます。どの段が時間を使っているかで、遅くなっている原因（デコード・画像処理など）を切り分けられます。 一時停止中は「—」になります。動画の書き出し中は表示しません。

プロパティ（詳細情報）

「ファイル」→「プロパティ…」（Ctrl+I）で、開いている動画の詳細な情報を表示します。

  • 全般：形式、サイズ、長さ、総ビットレート、作成日時、エンコーダなど
  • 映像：コーデックとプロファイル、解像度、アスペクト比、フレームレート（固定 / 可変）、ビット深度、色の情報（色域・伝達特性など）、B フレームの有無など
  • 音声・字幕など：コーデック、チャンネル、サンプリングレート、言語など

値はマウスで選択してコピーできます。「クリップボードにコピー」で全体をテキストとしてコピー、「名前を付けて保存…」でテキストファイル（元のファイル名_info.txt）に保存します。

画像処理

ヘッダーの「画像処理」でパネルを開き、上のタブで「画像処理」と「表示ツール」を切り替えます。

「画像処理」と「表示ツール」の違い 「画像処理」は映像そのものを変えます。ヒストグラム、画像の保存、動画の書き出しにも反映されます。
「表示ツール」は画面での確認用です。ヒストグラム、画像の保存、動画の書き出しには反映されません。

共通の操作

  • 各項目の右のスイッチで ON / OFF。OFF の間は設定を変更できません。
  • 項目名をクリックすると設定欄を開閉します。
  • スライダーをダブルクリックすると、その項目を初期値に戻します。
  • 数値欄はクリックして直接入力（Enter で確定、Esc で取り消し）、ホイール・↑↓・▲▼ でも変更できます（Shift で 10 ずつ）。
  • 処理は上から順に適用されます。

画像補正

明るさ全体を明るく / 暗くします。
コントラスト明暗の差を強く / 弱くします。
シャドウ暗い部分だけを持ち上げる（＋）/ 沈める（−）。
ハイライト明るい部分だけを抑える（−）/ 持ち上げる（＋）。
ガンマ中間の明るさを調整します（1.00 で変化なし）。

色補正

彩度色の濃さ（0 で白黒、100 で変化なし）。
色温度＋ で暖色（赤み）、− で寒色（青み）。明るさは保たれます。
ティント＋ でマゼンタ寄り、− でグリーン寄り。
R / G / Bタブでチャンネルを選び、ゲイン（倍率）・オフセット（足す量）・ガンマを個別に調整します。変更したチャンネルのタブには印が付きます。

トーンカーブ

  • 「RGB」（全体）/「R」/「G」/「B」のタブを切り替えて編集します。全体のカーブを掛けた後に、各チャンネルのカーブを掛けます。
  • クリックで点を追加、ドラッグで移動、ダブルクリックまたは右クリックで削除します。点は最大 16 個です。
  • 両端の点は上下にだけ動かせ、削除できません。
  • カーブは点を滑らかにつなぎ、点の間で行き過ぎて波打つことはありません。

ガウシアン（ぼかし / シャープ化）

  • 処理：「ぼかし」または「シャープ」。シャープは輪郭を強調し、「強さ」で効き具合を調整します。
  • サイズ：3 × 3 / 5 × 5 / 7 × 7 / 9 × 9。大きいほど広い範囲に効きます。
  • σ：ぼかしの広がり。
  • 係数：係数の濃淡を表示します。「係数を編集…」でセルごとに値を直接入力できます。「リセット」で計算した値に戻ります。サイズまたは σ を変えると係数は計算し直され、編集した値は失われます。
  • 正規化：ON にすると係数の合計が 1 になるよう調整し、全体の明るさを保ちます。

ソーベル（輪郭）

  • エッジ表示：輪郭だけを白黒で表示します。
  • ピーキング：元の映像に、輪郭を色付きで重ねます。ピント合わせの確認に使います。しきい値と色（赤・緑・青・黄・白）を選べます。

平均化

周囲の画素を平均してなめらかにします。サイズ・正規化・係数の編集はガウシアンと同じです。

表示ツール

画面での確認用の機能です。ヒストグラム、画像の保存、動画の書き出しには反映されません。

比較表示

  • 画面を「左右」または「上下」に分け、片側に補正前（画像処理なし）、反対側に補正後を表示します。
  • 境目は映像上でドラッグして動かせます（境目の中央の丸を掴みます）。位置は数値でも指定できます。
  • 境目の両側に「補正前」「補正後」のラベルを表示します。

チャンネル表示

R / G / B / 輝度 のどれか 1 つだけを白黒で表示します。

タイル境界チェック

タイル分割された動画で、タイルのつなぎ目を確認します（タイル分割でない動画では使えません）。

  • 境界線：タイルの境目に線を引き、左上にタイル番号を表示します。
  • 段差の強調：境目をはさんだ明るさの差が、周りに比べて不自然に大きい部分を色で強調します。しきい値で感度を調整します。
  • 線と強調の色は、映像に合わせて見やすい色を選べます。

スポイト

  • 映像の上にマウスを置くと、その画素の座標・フレーム番号・R / G / B・輝度をカーソルの横に表示します。
  • 表示する値は「補正後」「補正前」「両方」から選べます。
  • 値は表示中のフレームに合わせて更新されます。大きく拡大すると、読み取っている画素が枠で囲まれます。

ゼブラ

  • 白飛び警告：指定したレベル（輝度 %）以上の部分に黒の斜め縞を表示します。
  • 黒つぶれ警告：指定したレベル以下の部分に青の斜め縞を表示します。

  • 保存先と形式は、「保存」の横のボタンで設定します。

動画の書き出し（エンコード）

ヘッダーの「ファイルを保存」、または「ファイル」→「ファイルを保存…」でエンコード設定を開きます。 再生範囲（開始〜終了）を、画像処理を反映した状態で書き出します（表示ツールは反映されません）。

一般設定

保存パス書き出すファイル。拡張子を変えると録画フォーマットもそれに合わせます。
録画フォーマットMP4 / MKV / MOV。選んだ形式によって使えるコーデックが変わります。
コーデックH.264 / HEVC / AV1（GPU が対応しているものだけ表示）。
プロファイルHEVC は Main（8bit）/ Main 10（10bit）、AV1 は Main（8bit）/ Main（10bit）。H.264 は 8bit のみです。 10bit を選べるのは 10bit 以上の動画のときで、画像処理の結果を劣化させずに書き出せます。
ディザあり（なめらか）/ なし（値そのまま）。10bit 以上の動画を 8bit で書き出すとき（H.264、または 8bit のプロファイル）だけ表示されます。「あり」は細かいノイズでグラデーションの縞を目立たなくします（低いビットレートでは効果が薄れます）。画素の値をそのまま使いたいときは「なし」にします。

タイル分割1 / 2 / 4 / 8 タイル。映像を分割して複数のエンコーダで並列に書き出します。タイルごとに別のファイルになり、音声は 1 つ目のタイルのファイルに入ります。

ゲイン音量の調整（0 dB で変化なし）。

マルチ GPU 重み付け設定

GPU が複数ある場合、重み（0〜10）に応じて各 GPU のエンコーダにタイルを割り当てます。映像を描いている GPU（Primary）は必ず使われます。 AV1 に対応していない GPU は、AV1 を選ぶと自動的に外れます。

各 GPU の使用状況を、直近 60 秒のグラフで表示します（設定画面を開くたびにリセット）。

実行

  • 「エンコード開始」で書き出しを始めます。進捗、フレーム数、書き出しの速さ（fps）を表示します。
  • 「キャンセル」で中止します。途中までのファイルは正しく閉じられます。
  • 書き出し中は後ろの画面は止まって見えます。設定画面を閉じると、開いたときの位置と再生状態に戻ります。

マルチ GPU デコード

GPU を 2 枚以上積んだ PC では、タイル分割された動画（8K / 16K など）のデコードを複数の GPU に分担させられます。1 枚の GPU のデコーダ（NVDEC）では追いつかない高解像度・高フレームレートの再生に使います。

「ファイル」→「デコード設定…」で開きます。

重みGPU ごとに 0〜10。タイルを重みの比で振り分けます。0 の GPU はデコードに使いません。初期値は表示用の GPU だけが 10 です（従来どおり 1 枚でデコード）。
性能の低い GPU は重みを小さくします（例：表示用 10、サブ 4 → 4 タイルなら 3 本と 1 本）。
このファイルタイル分割の動画を開いているとき、今の重みで各 GPU が受け持つタイル数の見込みです。
NVDEC設定を開いた時点の各 GPU のデコーダの使用率です。

デコーダはファイルを開くときに作るので、設定は次にファイルを開いたときから使われます。「OK して開き直す」を押すと、今のファイルを開き直し、今の位置から再生を続けます。

  • 表示用以外の GPU でデコードしたタイルは、表示用の GPU へ転送します。転送の時間がかかるので、GPU 同士の転送が速い構成ほど効果があります。
  • そのコーデックをデコードできない GPU（AV1 は RTX 30 シリーズ以降）は自動で外します。
  • 分担の効果は性能 HUD の「NVDEC」（GPU ごとの使用率）と「デコード上限（目安）」で確認できます。
  • 転送の圧縮（試験的）：GPU 間の経路が細い構成（例：サブ GPU のスロットが PCIe x4）では、転送が詰まって fps が伸びないことがあります。デコード設定の「転送の圧縮」で Cascaded / Bitcomp / ANS を選ぶと、圧縮してから送ります（「差分」は圧縮の前に隣の画素との差に置き換える前処理）。効果は映像の内容によって変わるので、性能 HUD の「圧縮率」「転送」「展開」で確かめ、効果がなければ「なし」に戻してください。
  • タイル分割されていない動画は 1 枚の GPU でデコードします。

設定の保存

画像処理・表示ツールの設定、再生速度・音量、画像保存とエンコードの設定、表示の ON/OFF などは、アプリの終了時に setting.ini（アプリと同じフォルダー）へ保存され、次回起動時に元に戻ります。

  • 係数を直接編集した値は保存されません（サイズ・σ・正規化は保存されます）。
  • 設定を初期状態に戻したい場合は、アプリを終了してから setting.ini を削除してください。

困ったとき

ボタンが押せない

読み込み、高精度シーク、画像の保存などの処理中です。しばらく待ってください。戻らない場合は「ファイル」→「ファイルを閉じる」で閉じて、開き直してください。

「非対応フォーマットです」と表示される

MP4 / MKV / MOV / AVI 以外は開けません。MKV / MOV で GPU デコードの条件（対応ファイル）を満たさない場合も開けません。

描画フレームレートが目標に届かない

  • 動画情報の GPU グラフで、NVDEC・GPU が 100% 近くになっていないか確認してください。
  • 画像処理を減らす、フィルタのサイズを小さくする、再生速度を下げると改善することがあります。

CUDA の項目が表示されない / 「3D+CUDA」になっている

Windows の「ハードウェア アクセラレータによる GPU スケジューリング」が有効な場合、CUDA の使用率は 3D に含まれて表示されます。異常ではありません。

10bit の動画の扱い

10bit 以上の動画は自動的に 16bit の精度で処理します（8bit の動画は従来どおり 8bit で処理）。スポイトの値も 0〜1023 で表示します。 動画の書き出しは HEVC / AV1 なら 10bit で行えます（エンコード設定の「プロファイル」で Main 10 / Main（10bit））。画像の保存は PNG / TIFF なら 10bit を選べます（画像保存設定の「ビット深度」。16bit 形式のファイルに劣化なく格納）。JPEG / BMP は 8bit です。

画面への表示も 10bit で行います。動画情報の「Process/Render Depth」の後ろ側が 10bit なら、10bit で画面に出ています。 10bit → 8bit と出る場合は、アプリは 10bit で出していますが、画面に出るまでのどこかで 8bit に落ちています。次の 2 つを確認してください。

  • Windows の画面合成：通常の設定では、Windows はウィンドウ表示の画面を 8bit で合成します。ウィンドウ表示のまま 10bit で見るには、次のどれかが必要です。
    • NVIDIA のドライバ設定「Deep color for 3D applications」が有効（既定で有効。NVIDIA RTX など、対応する GPU とドライバの場合）。ドライバが合成を通さずに 10bit で出します。
    • Windows の「設定 → ディスプレイ」で 自動カラー管理（Windows 11）または HDR を有効にする。
    全画面表示では合成を通らずに出るので、これらの設定がなくても 10bit になります。
  • モニターへの出力：NVIDIA コントロールパネルの「出力の色深度」を 10bpc にします（モニターが 10bit 入力に対応している必要があります）。

設定を変えた後は、アプリのウィンドウをクリックすると表示が更新されます。 GPU・ドライバが 10bit 表示に対応していない場合は 8bit で表示され、ほかの動作は変わりません。

書き出しが始まらない・途中で止まる

  • エンコーダの初期化に失敗した場合は、設定画面にメッセージを表示します。解像度・タイル分割・B フレームを下げると改善することがあります。
  • GPU メモリが足りない可能性があります。VRAM のグラフと想定使用量を確認してください。
